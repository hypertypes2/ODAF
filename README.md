# On-Device Air Flow

Streamlit 기반의 On-Device Air Flow 데이터 분석 및 모델 설계 파이프라인입니다.

## 실행 방법

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run main.py
```

## 주요 기능

- 데이터 분석 단계
- 모델 설계 단계
- TFLite 변환 단계
- 배포용 인터페이스

## 배포

이 프로젝트는 GitHub 저장소에 연결해 Streamlit Cloud 또는 다른 호스팅 환경에서 배포할 수 있습니다.
